# ちらり Chirari: learn Japanese at a glance

Prototype for PBE II (Advanced) Mid-Term 2.

- **Web app:** `index.html` (served by GitHub Pages)
- **Android app:** `android/`, with a real home-screen widget that shows one work or daily-life word every hour
- **APK download:** built automatically by GitHub Actions on every change, published on the Releases page as `chirari.apk`

Words: 230 (Konbini & Retail, Hotel, Factory, Daily Life) with meanings in English, Vietnamese, Burmese and Nepali. Non-English text is a draft waiting for native-speaker checks.
